## La plataforma de producte darrere de l'estudi

Doscientos no és només una web comercial. He construït de punta a punta la seva capa de producte digital, de manera que la forma de presentar l'estudi, operar el dia a dia i reutilitzar enginyeria forma un únic sistema connectat.

### Web pública
La web presenta la feina de l'estudi i els seus productes digitals amb una estructura de contingut clara i patrons de frontend reutilitzables.

### Backoffice operatiu
El backoffice propi centralitza el treball diari d'empreses, leads, clients, tasques de projecte i facturació. Dóna a l'equip una única font de veritat en lloc d'una col·lecció d'eines i fulls de càlcul desconnectats.

### Ecosistema de paquets compartits
Cinc paquets reutilitzables converteixen patrons transversals en blocs mantinguts. Així reduïm feina duplicada, les millores arriben de manera centralitzada a tots els productes i l'entrega es manté consistent a mesura que creix l'estudi.

### MCP i skills especialitzades
He ampliat l'stack operatiu amb una capa MCP i skills especialitzades perquè els assistents d'IA puguin recuperar context intern autoritzat i ajudar en les tasques on es fa la feina. L'accés està acotat per tasca, sense exposar dades de negoci en brut.

## El meu paper

Lidero l'enginyeria de la plataforma de producte de l'estudi, des de l'arquitectura i la implementació frontend fins a la revisió de codi, el rendiment i el manteniment. Treballo en la web pública, les eines internes i els paquets compartits per mantenir un sistema coherent.

## Àrees d'enginyeria

- **Arquitectura de producte:** connectar la web pública, el backoffice operatiu, els paquets compartits i les integracions.
- **Eines operatives:** donar suport als fluxos d'empreses, leads, clients, tasques de projecte i facturació.
- **Sistemes compartits:** mantenir cinc paquets amb patrons reutilitzables i millores aplicables a diversos productes.
- **Integracions d'IA:** crear eines MCP i skills amb accés limitat al context autoritzat per a cada tasca.
