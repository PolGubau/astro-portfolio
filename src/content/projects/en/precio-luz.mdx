**Precio Luz** is an independent product I built around an everyday question: how much does electricity cost today, and when is the best time to use each appliance? It is not a Doscientos project.

It turns hourly data into a direct, understandable and useful check from any phone, with no accounts or unnecessary steps.

<Image src={cover} alt="Precio Luz interface showing electricity prices by hour" class="rounded-2xl my-6" />

---

## Designed for quick decisions

The interface prioritises the data that helps people act: the current price, the cheapest and most expensive hour, and a complete view of all 24 hours. Every relevant detail is available as soon as the tool opens.

Alongside each hourly price, it can estimate the approximate cost of using a household appliance at a specific time.

## Public data, no friction

Prices update automatically from data published by Red Eléctrica de España. The result is a free, production-ready tool that turns public data into a practical answer.
